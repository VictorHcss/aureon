# Prints do Aureon

Capturas do build de produção (`next start`), feitas com Chromium em alta resolução: 2× no desktop (1440×900) e 3× no celular (390×844).

> Os produtos, preços e alertas que aparecem são **dados de demonstração**, servidos por um banco falso local só para as capturas. Nenhum desses dados existe no código do projeto.

| Arquivo | O que mostra |
|---|---|
| `00-capa-linkedin-1200x627.png` | Capa horizontal (formato de imagem de post/link do LinkedIn) |
| `00-capa-linkedin-1080x1350.png` | Capa vertical (ocupa mais espaço no feed) |
| `01-visao-geral-claro/escuro` | Visão geral: indicadores, oportunidades, gráfico, última coleta e alertas |
| `03-produto-claro/escuro` | Comparação entre lojas de um produto |
| `03b-produto-grafico-claro/escuro` | Histórico de preços com o gráfico por loja |
| `04-produtos-claro/escuro` | Lista de produtos monitorados com filtros |
| `05-login` | Tela de login |
| `06-coletas-claro/escuro` | Histórico de coletas e envios |
| `07` a `09-celular-*` | As mesmas telas no celular |
| `10-celular-menu-claro/escuro` | Menu em gaveta no celular |
